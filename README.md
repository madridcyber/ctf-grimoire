## 📖 What is this?

My personal collection of **CTF writeups and battle records** — documenting every challenge I solve on the path from Adept to Grandmaster.

## 🗂️ Structure

```
ctf-grimoire/
└── <year>/
    └── <event-or-platform>/
        └── <challenge-name>.md
```

Start from [`template/writeup-template.md`](./template/writeup-template.md).

## 📜 Rules of the Grimoire

- Writeups for **active competitions** are published only after the event ends
- Everything here was done on **legal platforms** (CTF events, HackTheBox, TryHackMe, OverTheWire)
- Knowledge is for building and defending — not for harm
